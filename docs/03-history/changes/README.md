# Registro de cambios

Cada cambio tiene un identificador `CHG-AAAA-MM-NNN` y un archivo con su pedido, verificación, riesgos y rollback. El identificador también va en sus commits, para pasar de un documento al código y viceversa.

Para crear uno, copiá `_TEMPLATE.md`. La guía de uso está en [`traceability.md`](../../01-engineering/traceability.md).

Los cambios anteriores a CHG-2026-11-001 no tienen registro: se rastrean con los tags de versión, `CHANGELOG.md` y `docs/03-history/`.
